# Boxen an der Uni Vechta – Website

Statische One-Page-Website (HTML, CSS, JavaScript – ohne Build-Schritt) für das Boxtraining im Hochschulsport der Universität Vechta.

## Ansehen

`index.html` einfach im Browser öffnen oder lokal starten:

```bash
cd website
python3 -m http.server 8000
```

## Vor der Veröffentlichung anpassen

Folgende Inhalte sind **Platzhalter** und müssen ersetzt werden:

- Trainingszeiten und Ort (Abschnitt `#training` in `index.html`)
- Namen und Beschreibungen des Trainerteams (`#team`)
- E-Mail-Adresse `boxen@example.de` (in `index.html` und `script.js`)
- Instagram-Account
- Links zu Impressum und Datenschutz im Footer
